## 1. Intent & Architectural Justification

Elevate agent code execution security from standard Docker containers to hardware-assisted microVMs (AWS Firecracker) and sandboxed user-space application kernels (Google gVisor `runsc`). This guarantees that untrusted, autonomous code generated by agents cannot escape the container boundary, leak sensitive credentials, access unauthorized network interfaces, or exploit host Linux kernel vulnerabilities.

---

## 2. Capabilities & Deliverables

1. `src/core/eosFirecrackerMicroVmEngine.types.ts` & `src/core/eosFirecrackerMicroVmEngine.ts`:
   - `FirecrackerConfigGenerator`: Generates compliant Firecracker VM specs (`machine-config`, `boot-source`, `drives`, `vsock`).
   - `GvisorConfigGenerator`: Synthesizes OCI `config.json` specs targeting `runsc`.
   - `HardwareVirtualizationProber`: Probes `/dev/kvm`, CPU hypervisor extensions (VT-x/AMD-V), and binary paths.
   - `HermeticMicroVmOrchestrator`: Dispatches code execution across Firecracker, gVisor, or isolated process jails.
   - `auditMicroVmPipeline`: Verifies isolation, resource constraints, network blocking, and generates `docs/evidence/MICROVM_SANDBOX_RECEIPT.json`.
2. CLI subcommands in `bin/commands/cliMicroVmEngine.mjs` and delegation in `bin/commands/cliToolchainRouter.mjs`:
   - `toolchain:microvm:launch`: Launches code execution in isolated microVM/sandbox.
   - `toolchain:microvm:config`: Emits declarative Firecracker or gVisor configuration JSON.
   - `toolchain:microvm:diag`: Diagnoses host hardware virtualization capabilities.
   - `toolchain:microvm:audit`: Runs security validation audit and emits cryptographic receipt.
3. BDD test suite: `test/eosFirecrackerMicroVmEngine.test.mjs` verifying BDD-1545..1550.

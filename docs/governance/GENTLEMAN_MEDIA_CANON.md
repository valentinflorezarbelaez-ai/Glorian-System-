## Operating principles agents MUST honor
1. Configure agents already installed; do not silently install agent runtimes.
2. Engram persists decisions, conventions, and bug fixes — sessions must not start from zero.
3. Requirements / exploration before code; one focused question when a real decision is open.
4. Test-first, small human-readable commits; tests and docs travel with the code.
5. Verification over generation — quality first, speed as a consequence.
6. ODD scales: low-risk inline; large work gets a feature document in the user's words.
7. SDD / OpenSpec skills guide the AI; the model is not the process.
8. Review on by default; humans retain merge authority.

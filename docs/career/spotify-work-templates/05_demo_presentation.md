# Demo / Show & Tell (EN)

## 60-second pitch (speak this)
“We had `<problem for listener/artist>`. We shipped `<change>`. Here’s proof `<metric/URL>`. Ask: `<merge / feedback / decision>`.”

## Storyboard (3–5 min)
1. **Problem** — who hurts (user · artist · music)  
2. **Before** — broken path  
3. **After** — live demo / screenshots  
4. **Proof** — tests, metrics, canary  
5. **Ask** — one clear decision

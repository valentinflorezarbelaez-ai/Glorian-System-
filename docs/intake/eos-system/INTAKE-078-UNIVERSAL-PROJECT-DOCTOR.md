# INTAKE-078: Universal Project Doctor & SDLC Acceleration Engine

- **Owner directive**: Expand Glorian System so it can assist, diagnose, and accelerate development on any software project of any complexity (Node/TS, Python, Go, Rust, Java, C/C++) with maximum efficiency and quality across Cursor and Google Antigravity.
- **Gap**: While Glorian has specialized internal audits, it lacks an all-in-one universal project doctor CLI (`glorian doctor [path]`) and MCP tool that inspects any external codebase, calculates a Spotify Soundcheck 0-100 score, detects security/secret risks, and auto-synthesizes tailored CI/CD workflows under zero runtime dependencies.
- **Outcome**: A pure Layer-0 Universal Project Doctor (`src/core/eosUniversalProjectDoctor.ts`) providing polyglot stack detection, 5-pillar soundcheck scoring, secret sanitization scanning, and automated CI/CD pipeline synthesis accessible via CLI (`glorian doctor`) and MCP (`eos_enterprise_workspace` with `action: "doctor"`).

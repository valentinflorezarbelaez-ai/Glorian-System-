## 1. Business Context & Engineering Rationale
In Frontier Level 19, codebases must autonomously shed technical debt, eradicate dead code, and optimize algorithms while developers sleep.
Glorian System already possesses:
- `EosEvolutionaryHarness` (AlphaEvolve multivariate fitness evaluation).
- `EosContinuousRefactorEngine` (dead code elimination and token duplication detection).
- `EosMutationTester` (mutation testing and survival verification).

This initiative synthesizes these capabilities into a single, unified nocturnal engine and CLI command: `glorian night:evolve` / `eos night:evolve`.

## 2. Capability Scope
- **Autonomous Nocturnal Sweep**: Scans target modules or repositories for dead exports, duplication hotspots, and cyclomatic bottlenecks.
- **Multivariate Fitness Evaluation**: Computes the DeepMind AlphaEvolve fitness vector (AST purity, lines saved, complexity reduction, contract compliance).
- **Automated Refactoring & Patch Synthesis**: Generates non-destructive AST cleanup proposals with zero regression verification.
- **Cryptographic Evolution Receipt**: Emits a SHA-256 sealed attestation of lines saved and debt eradicated, logged monotonically to `EosDurableSqliteLedger`.
- **Layer-0 Compliance**: Zero external runtime dependencies, 100% pure Node.js built-ins.
